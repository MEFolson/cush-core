# Cush Core

The core a global bank can examine.

Licensed, AI-native core banking for global banks and financial institutions. One immutable ledger. Agents under the institution’s mandate. On-ramp and off-ramp on the same book.

This repository is the institutional site — distinct from [Cush Payments](https://github.com/MEFolson/cush-payments).

## Stack

TanStack Start, React, Tailwind v4.

```bash
npm install
npm run dev
```
